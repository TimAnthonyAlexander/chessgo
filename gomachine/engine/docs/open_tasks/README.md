# Task docs

Lightweight, self-contained task files. One file per task.

- **`docs/open_tasks/`** — not started or in progress.
- **`docs/done_tasks/`** — completed. **Move** the file here when done (don't delete);
  add a `## Outcome` section with what actually happened + the SPRT/measurement numbers,
  so the finished file is a record, not a stub.

Each task file should be actionable enough that a fresh instance can execute it without
re-deriving context: what, why, the concrete command(s), acceptance criteria, cadence.

## Gotchas learned
- **Background-monitor self-match:** `pgrep -f "bench spsa"` matches its own poll-shell (and any ssh
  command that echoes the string) → monitors get stuck "RUN forever" and never fire. Use the bracket
  trick `pgrep -f "[b]in/gomachine bench spsa"` **in a clean ssh that doesn't also contain the launch
  string.** Several early monitors this session were silently stuck for this reason.
- **coalla ssh is flaky under heavy load** (SPSA at conc 12); scp/rebuild works once load drops. Kill
  with `pkill -f "[b]in/gomachine bench <spsa|sprt>"`.
- **coalla SIMD build:** `GOEXPERIMENT=simd GOAMD64=v4 ~/go/bin/go1.26.4 build -o bin/gomachine
  ./cmd/gomachine`. A plain `go build` is a scalar binary — invalid for movetime/NPS.
- **Feel-SPRTs run contended with a live SPSA** (conc 4 vs conc 12) are symmetric self-play → OK
  directionally, noisier; kill the SPSA to un-contend if the SPRT is the priority.
- **Fixed-nodes SPSA flatters "prune more"** — always validate converged θ at movetime before shipping
  (rfpmargin was the mirage this session).

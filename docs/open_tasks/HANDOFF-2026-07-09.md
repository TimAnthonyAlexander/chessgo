## 0. TL;DR (the decisions)

1. **int8-FT threat quantization is a 0-Elo wash** (measured, SPRT — not assumed). Keep it **ON** (free speed). The whole "FT-weight QAT leak" thread is **dead as a standalone lever** — the ~51 Elo was a *fixed-depth* number that collapses to 0 in real play. **Do NOT build the bullet QAT patch for the lean net.**
2. **We have the frontier feature *types* (threats + 16 KB h-mirror + int8-threat FT + 8 buckets) but NOT their *richness*.** ⚠️ Corrected 2026-07-09: our threats = **9,216** features vs SF **79,856** / Stormphrax **64,368** — we're ~8× coarser (victim-square + types only; no attacker-from / king context). The **input-richness gap is bigger than the width gap** (512 vs 640/1024) — *bigger gap, but width still goes FIRST (cheaper to test; §4C→D)*. Plus the tail: we ship lean single-layer int16; the frontier runs a small **int8/VNNI multilayer** tail (built but shelved — it lost at 512, but on the *slow* tail, at only +32 float ceiling).
3. **Plan (revised — see §4):** free VNNI+sparse prep (A) → **B: go/no-go on the int8/VNNI multilayer tail at H=512** (a *package* test — 4 vars change, not single-variable) → **C: width 512→768** (the cheap ~1.09× read on whether width is alive) → **D: threat-richness expansion** (the bigger build, priced after C). NOT "wide + multilayer in one run" (confounds vars; the width tax is only ~1.09×, so test the *tail* at fixed 512 first). Gate everything on the free prep so no run is a slow-tail artifact.
4. **SPSA is a diminishing ~+5 background freebie**, not a headline. (Correction: the +38 was the *first* SPSA reclaiming weeks of HCE-era constant drift; the *last* run was ~+5. Constants are near-converged.)
